NYC Bike Data Analysis – Excel Project
Overview:
    This project demonstrates end-to-end data analysis in Excel using the New York City Bike Dataset.
It covers everything from basic formulas to advanced reporting automation with Pivot Tables and Macros.
The goal is to build practical Excel skills for a Financial/Data Analyst role by working on a real dataset.


Features & Steps Covered:
Excel Formulas & Functions-
    Convert Trip Duration (seconds → hours)
    INDEX-MATCH
    Convert Month Number → Month Name
    Error handling with IFERROR for cleaner reports

Data Cleaning & Transformation-
    Extract Month from Date.
    Created helper columns for reporting.

Pivot Tables & Reporting-
    Pivot Table: Month vs User Type → Average Duration & Ride Count.
    Applied custom formatting & conditional highlights.
    Grouped by Month for better analysis.

Macros & Automation-
    Recorded Macro to:
        Refresh all PivotTables.
        Format headers (bold, centered, autofit, colored).



Skills Demonstrated:
    Advanced Excel: Formulas, Functions, PivotTables, Conditional Formatting.
    Automation: Macros & VBA (report refresh + formatting).
    Data Analysis: Aggregation, reporting cycles, trend insights.
    Problem-Solving: Handling large datasets, error checking, automation.
