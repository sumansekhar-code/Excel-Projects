Overview

The Sales Data Analysis project aims to analyze sales data for a company to uncover trends,
forecast future sales, and identify key revenue-generating products or services. This project
demonstrates the use of data analysis and visualization techniques to support better business decision-making.

Project Objectives:
  Uncover sales trends and patterns.
  Identify top-performing products, categories, and regions.
  Generate actionable insights to improve business performance.
  Build interactive dashboards to communicate findings effectively.

Tools and Technologies:
  Excel → Data cleaning & Dashboard design

Key Results:
  Visualized sales trends over time using line and bar charts.
  Identified top-performing products and categories.
  Created regional sales dashboards for comparative analysis.
  Built heatmaps and distribution charts for customer segmentation insights.
  Analyzed profit vs discount correlations to understand pricing strategy impact.

Deliverables:
  Interactive dashboards
  Charts & visualizations
  Business insights to support decision-making
